Notes for Daily Git Usage

cd C:\xampp\htdocs\dpk_pvt_csbk

- pull latest from github
git pull origin main

- Check Current Status of Your Project
git status

git fetch origin

git log HEAD..origin/main --oneline
git diff --name-only HEAD origin/main

- View Commit History (in Long Form)
git log
git log --oneline

- Stage All Changed Files
git add .

- To move back to last staging but not last commit - this command takes you back to last git add .
git restore .

- Commit Changes with a Message
git commit -m "message here"

- Push Your Code to GitHub
git push -u origin main

git reset --hard HEAD && git clean -fd
